# v0.2.0-preview

[日本語版](v0.2.0-preview.ja.md)

`v0.2.0-preview` brings the current six-adapter mainline to the public Docker
and binary distribution channels. It remains a selected-workflow compatibility
release, not a claim of full provider parity.

## Highlights

- Six `workflow-compatible` adapters: Stripe, OpenAI, GitHub OAuth, Slack, LINE, and Zoho OAuth.
- Generated compatibility scores, manifests, known gaps, and release gates.
- Official Stripe, OpenAI, and LINE Node.js SDK contracts for selected workflows.
- Deterministic fake state, reset endpoints, bounded request history, and replayable reports.
- AI-safe secret and external-URL checks with deployment warnings reported separately from `public_env_safe`.
- Runnable Node.js SDK examples and `llms.txt` guidance for AI coding agents.

## Install

```bash
docker pull ghcr.io/albert-einshutoin/mockport:0.2.0-preview
docker run --rm -p 127.0.0.1:43101:43101 \
  -v $(pwd)/examples/stripe-checkout/mockport.yml:/etc/mockport/mockport.yml \
  ghcr.io/albert-einshutoin/mockport:0.2.0-preview \
  run --config /etc/mockport/mockport.yml --host 0.0.0.0
```

Binary archives and `checksums.txt` are published on the GitHub Release page.

## Migration from v0.1.0-alpha

Existing configuration remains valid. Update pinned Docker references and
generated Compose files to `0.2.0-preview`. Run `mockport init --force` only when
you intentionally want to replace existing generated files.

## Known limits

- Compatibility covers documented selected workflows, not provider internals or every official SDK call.
- OpenAI Responses SSE, real LINE Login/LIFF, complete Slack Events/Block Kit, and full Stripe billing/network behavior remain out of scope.
- State is process-local and resets when Mockport restarts.
- Homebrew and npm remain unpublished/experimental distribution paths.

See the [compatibility report](../compatibility-reports/latest.md),
[support matrix](../site/support-matrix.md), and [limitations](../site/limitations.md).
