# v0.2.0-preview 日本語版

[English](v0.2.0-preview.md)

`v0.2.0-preview` は、現在の6 adapter mainline を Docker image と binary archive
として公開する selected-workflow compatibility release です。provider 全体の完全互換を
主張するものではありません。

## 主な変更

- Stripe、OpenAI、GitHub OAuth、Slack、LINE、Zoho OAuth を `workflow-compatible` として提供。
- compatibility score、manifest、known gap、release gate を追加。
- 公式 Stripe、OpenAI、LINE Node.js SDK contract を selected workflow で検証。
- deterministic fake state、reset endpoint、bounded request history を追加。
- `public_env_safe` を credential/URL safety に限定し、deployment warning と分離。
- 実行可能な Node SDK example と AI coding agent 向け `llms.txt` を追加。

導入コマンド、移行方法、known limit、検証方法は英語版を正とします。
